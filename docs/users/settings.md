# Paramètres

[← Guide utilisateur](./README.md)

## Dossier de travail

Affiche le dossier actuellement utilisé par Influencor.

Action disponible:

- **Changer de dossier de travail**: sélectionne une autre bibliothèque.

## Apparence

Options disponibles:

- thème système;
- thème clair (par défaut);
- thème sombre.

## Vue par défaut

Choisissez l'affichage préféré de la bibliothèque:

- grille;
- liste.

## Langue

Langues disponibles dans l'application:

- Malagasy;
- Français;
- English.

## Séparateur de note

Le séparateur de note contrôle la séparation des blocs en mode lecture et
partage.

Vous pouvez garder la valeur par défaut ou définir un séparateur personnalisé.

## Informations

L'écran paramètres affiche aussi le nom de l'application et le crédit créateur.
